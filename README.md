# study.rayanupadhyay.com

A cozy study room: a rainy window, ambient sounds, a focus timer, and a to-do list on one screen.

**Live:** [study.rayanupadhyay.com](https://study.rayanupadhyay.com)

## Features

- **Sounds:** rain, deep focus (brown noise), waves, wind, and fireplace. Mix any of them, each with its own volume slider. The rain on the window gets heavier when the rain sound is on.
- **Focus timer:** 25 minute focus sessions with 5 minute breaks and a 15 minute long break every fourth session. A soft chime plays when time's up.
- **To-do list:** add tasks, tick them off, clear finished ones.
- **Clock** in the corner.

Your tasks, volume levels, and today's session count are saved in the browser on your device.

## Tech

One `index.html` file. Plain HTML, CSS, and JavaScript. All sounds are generated with the Web Audio API, so there are no audio files. Hosted on Vercel.
